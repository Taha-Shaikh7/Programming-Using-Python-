
# 🐍 Python from Zero To Hero

This repository contains a comprehensive collection of Python programming lab solutions completed as part of my university semester coursework. It covers fundamental to advanced Python concepts through well-structured programs, practical exercises, and problem-solving tasks.

- 🟢 Python Fundamentals

- 🔀 Conditional Statements
- 🔁 Loops and Iterations
- ⚙️ Functions
- 📋 Lists, Tuples, Sets, and Dictionaries

- 🧮 Data Structures and Problem Solving

2. Navigate to the project directory:

   ```bash
   cd Python-from-Zero-To-Hero
   ```

   ```bash
   python filename.py
   ```
